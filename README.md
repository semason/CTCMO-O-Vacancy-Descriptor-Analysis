# CTCMO O Vacancy Descriptor Analysis

Private working repository for the oxygen-vacancy descriptor analysis and manuscript-validation workflow for compositionally complex transition-metal oxides (CTCMOs).

## Contents

* `oxygen_vacancy_ml_manuscript_validation(1).ipynb` — primary analysis and validation notebook
* `descriptorsV3_ML_curated(1).csv` — curated descriptor dataset used for the primary ML analysis
* `vac-descriptorsV2_labeled(1).xlsx` — labeled oxygen-vacancy descriptor dataset used for the post-vacancy analysis

## Running the analysis

The notebook is designed to run in **Google Colab**.

Because this repository is currently private, open the notebook from the repository and then upload/open it in Colab manually.

The complete workflow takes several hours to run. When prompted by the notebook, upload the CSV and XLSX data files included in this repository.
